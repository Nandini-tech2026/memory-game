# Memory Match

A memory card game built with HTML, CSS and JavaScript.

## Features
- Enter your name and play
- Cards shuffle and show for 2 seconds
- 15 move limit: win or lose
- Sound on matches
- Leaderboard of best moves (saved with localStorage)
